# Google Cloud Platform (GCP)

Four Ways to Interact with Google Cloud

- [Google Cloud Console (Web GUI)](console.cloud.google.com)
- Cloud Shell and Google Cloud CLI  (Temp VM with 5 GB persistence)
- Client Libraries that exposes REST-based API: Java, Python, Node.js, Ruby, Go, PHP,... OAuth2 used for all authentication
- Cloud Mobile App: to manage VM, DB instance,  App engines, billing alerts and many more.
